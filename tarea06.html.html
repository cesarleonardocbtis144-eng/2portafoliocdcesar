CAP. I

Fundamentos de Python

¿Qué es Python?

Python es un lenguaje de programación de alto nivel, interpretado y de propósito general. Su filosofía de diseño hace énfasis en la legibilidad del código, usando indentación significativa para delimitar bloques.

Es uno de los lenguajes más populares del mundo: se usa en ciencia de datos, inteligencia artificial, desarrollo web, automatización, y mucho más.

✦
Dato clave: Python fue creado por Guido van Rossum y lanzado en 1991. Lleva su nombre por el grupo cómico Monty Python, no por la serpiente.

Instalación del entorno

Para comenzar a programar en Python solo necesitas tres cosas: el intérprete, un editor y tu primer archivo .py.

# 1. Descarga Python desde python.org
# 2. Verifica la instalación:
python --version
# → Python 3.12.x

# 3. Abre el intérprete interactivo:
python
>>> print("¡Hola, universo!")
# → ¡Hola, universo!
💡
Editores recomendados: VS Code (gratuito, extensión Python), PyCharm Community, o incluso el IDLE que viene incluido con Python.

Variables y Tipos de Datos

Una variable es un contenedor con nombre que almacena un valor en memoria. En Python no se declara el tipo — se infiere automáticamente.

# Tipos básicos de datos
nombre    = "Astro"           # str  → texto
edad      = 25               # int  → entero
altura    = 1.75             # float → decimal
activo    = True             # bool → verdadero/falso

# Verificar el tipo
print(type(nombre))          # <class 'str'>
print(type(edad))            # <class 'int'>

# Conversión de tipos (casting)
edad_texto = str(edad)       # "25"
numero     = int("42")       # 42

CAP. II

Estructuras de Control

Condicionales (if / elif / else)

Los condicionales permiten tomar decisiones: ejecutar un bloque de código solo si se cumple una condición.

temperatura = 22

if temperatura > 30:
    print("Hace calor 🌞")
elif temperatura > 15:
    print("Temperatura agradable ✨")
else:
    print("Hace frío 🌙")

# → Temperatura agradable ✨

# Operadores de comparación
# ==  igual a        !=  diferente de
# >   mayor que      <   menor que
# >=  mayor o igual  <=  menor o igual

Bucles (for / while)

Los bucles repiten un bloque de código múltiples veces. for itera sobre una secuencia; while repite mientras una condición sea verdadera.

# Bucle for con range()
for i in range(1, 6):
    print(f"Estrella {i} ✦")
# → Estrella 1 ✦  ...  Estrella 5 ✦

# Bucle while
contador = 0
while contador < 3:
    print(f"Vuelta {contador}")
    contador += 1

# Control de bucles
for n in range(10):
    if n == 5:
        break          # detiene el bucle
    if n % 2 == 0:
        continue       # salta esta iteración
    print(n)
💡
f-strings: La sintaxis f"texto {variable}" es la forma moderna de insertar variables dentro de cadenas. ¡Úsala siempre!

Listas y Diccionarios

Las listas almacenan colecciones ordenadas de elementos. Los diccionarios almacenan pares clave-valor.

# ── Listas ──────────────────────────────
colores = ["dorado", "azul marino", "blanco"]

colores.append("negro")       # agrega al final
print(colores[0])              # "dorado" (índice 0)
print(len(colores))            # 4

for color in colores:
    print(f"Color: {color}")

# ── Diccionarios ────────────────────────
perfil = {
    "nombre": "Astro Dev",
    "rol":    "Programador",
    "nivel":  1
}

print(perfil["nombre"])         # "Astro Dev"
perfil["nivel"] = 2            # actualiza valor

for clave, valor in perfil.items():
    print(f"{clave}: {valor}")
CAP. III

Funciones y Módulos

Definir y Usar Funciones

Una función es un bloque de código reutilizable con un nombre. Se define con def y puede recibir parámetros y retornar valores.

# Función básica
def saludar(nombre):
    return f"✦ Bienvenido al cosmos, {nombre}!"

print(saludar("Explorador"))
# → ✦ Bienvenido al cosmos, Explorador!

# Función con parámetros por defecto
def crear_tarjeta(nombre, rol="Desarrollador"):
    linea = "─" * 30
    return f"\n{linea}\n  {nombre}\n  {rol}\n{linea}"

print(crear_tarjeta("Ana García"))
print(crear_tarjeta("Luis Vega", "Diseñador"))

# Función con *args (múltiples argumentos)
def sumar_todo(*numeros):
    return sum(numeros)

print(sumar_todo(1, 2, 3, 4, 5))  # → 15

Módulos de la Biblioteca Estándar

Python viene con una enorme biblioteca de módulos listos para usar. Solo necesitas importarlos con import.

import random
import math
from datetime import datetime

# random: números aleatorios
dado = random.randint(1, 6)
print(f"Dado: {dado}")

# math: funciones matemáticas
print(math.sqrt(16))          # → 4.0
print(math.pi)               # → 3.14159...

# datetime: fecha y hora actual
ahora = datetime.now()
print(f"Hoy es: {ahora.strftime('%d/%m/%Y')}")
✦
Módulos esenciales para conocer: os (sistema de archivos), json (datos JSON), sys (sistema), re (expresiones regulares).

Código Completo del Proyecto

Aquí está el programa completo. Cada línea usa conceptos que aprendiste en esta guía:

"""
╔══════════════════════════════════════════╗
║   GENERADOR DE TARJETA DE PRESENTACIÓN  ║
║   Proyecto Final · Guía Python Básico   ║
╚══════════════════════════════════════════╝
"""
import random
from datetime import datetime

# ── Datos de la paleta (diccionario) ────
PALETA = {
    "azul_marino": "\033[34m",
    "dorado":     "\033[33m",
    "blanco":     "\033[97m",
    "reset":      "\033[0m"
}

# ── Habilidades disponibles (lista) ─────
habilidades_base = [
    "Python", "HTML/CSS", "Git",
    "JavaScript", "SQL", "Linux"
]

# ── Función: dibujar borde ───────────────
def borde(ancho=42):
    dorado = PALETA["dorado"]
    reset  = PALETA["reset"]
    return f"{dorado}{'═' * ancho}{reset}"

# ── Función: centrar texto ───────────────
def centrar(texto, ancho=40, color="blanco"):
    c = PALETA.get(color, "")
    r = PALETA["reset"]
    return f"{c}{texto.center(ancho)}{r}"

# ── Función: generar estrellas aleatorias ─
def estrellas(n=5):
    opciones = ["✦", "★", "✧", "◆"]
    return " ".join([random.choice(opciones) for _ in range(n)])

# ── Función principal: generar tarjeta ───
def generar_tarjeta(nombre, rol, skills):
    fecha = datetime.now().strftime("%d/%m/%Y")
    
    print(borde())
    print(centrar(estrellas(), color="dorado"))
    print(centrar(nombre.upper(), color="dorado"))
    print(centrar(rol))
    print(centrar("─" * 20, color="azul_marino"))
    
    # Mostrar habilidades con bucle
    for skill in skills:
        print(centrar(f"◆ {skill}", color="azul_marino"))
    
    print(centrar("─" * 20, color="azul_marino"))
    print(centrar(f"Generado: {fecha}"))
    print(borde())

# ── Programa principal ───────────────────
if __name__ == "__main__":
    print(centrar("GENERADOR DE TARJETAS", color="dorado"))
    
    # Input del usuario
    nombre = input("Tu nombre: ")
    rol    = input("Tu rol: ")
    
    # Seleccionar 3 habilidades aleatorias
    mis_skills = random.sample(habilidades_base, 3)
    
    # Validación con condicional
    if nombre and rol:
        generar_tarjeta(nombre, rol, mis_skills)
    else:
        print("⚠ Por favor ingresa nombre y rol.")
