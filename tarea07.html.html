¿Qué es Arduino?

Arduino es una plataforma de hardware y software libre que permite crear proyectos de electrónica interactivos de forma sencilla. Fue diseñada en 2005 en el Instituto IVREA (Italia) con el objetivo de acercar la electrónica a personas sin experiencia técnica.

Su núcleo es un microcontrolador programable que puede leer entradas (sensores, botones, señales) y convertirlas en salidas (activar motores, encender LEDs, enviar datos). Todo esto se controla mediante un lenguaje de programación basado en C/C++.

// CONCEPTO CLAVE
Arduino es como el cerebro de un proyecto electrónico: recibe información del mundo físico y decide qué hacer con ella.
🔓
Open Source
Diseños, esquemas y código disponibles libremente para todos.
💡
Fácil de aprender
Comunidad enorme con tutoriales, librerías y ejemplos listos para usar.
🔧
Versátil
Robótica, IoT, domótica, arte interactivo y mucho más.
💰
Económico
Una placa Arduino Uno cuesta menos de $10 USD en el mercado.
02

La Placa Arduino Uno

El modelo más popular y recomendado para aprender es el Arduino Uno R3. Conocer sus partes es el primer paso antes de conectar cualquier componente externo.

Componente Descripción Cantidad
Microcontrolador ATmega328P El "cerebro" de la placa. Procesa el programa. 1
Pines Digitales (D0–D13) Lectura/escritura de señales digitales (0V ó 5V). 14
Pines Analógicos (A0–A5) Lectura de valores entre 0 y 1023 (0V a 5V). 6
Pin 5V / 3.3V / GND Alimentación para componentes externos. Múltiple
Pin 13 con LED LED integrado en la placa, útil para pruebas. 1
Puerto USB tipo B Programación y alimentación desde computadora. 1
// IMPORTANTE
Los pines marcados con ~ (3, 5, 6, 9, 10, 11) son pines PWM: pueden simular señales analógicas mediante pulsos rápidos.
03

Componentes Esenciales

Antes de hacer cualquier proyecto necesitas reconocer los componentes electrónicos más comunes. Estos son los imprescindibles para comenzar:

💡
LED
Diodo emisor de luz. Tiene polaridad (+/-). Opera a 2–3.5V. Siempre usarlo con resistencia.
〰️
Resistencia
Limita el flujo de corriente. El valor se lee con el código de colores. Unidad: Ohm (Ω).
🔘
Pulsador (Button)
Interruptor momentáneo. Abre o cierra un circuito al presionarlo.
🌡️
Sensor LM35
Sensor de temperatura analógico. Salida lineal de 10mV por cada °C.
📡
Potenciómetro
Resistencia variable ajustable manualmente. Útil para controlar voltaje.
🔊
Buzzer
Genera sonido mediante vibraciones piezoeléctricas. Activo o pasivo.
// CONSEJO
Un kit Arduino básico incluye todos estos componentes por menos de $20 USD. Busca "Arduino Starter Kit" en tiendas locales o en línea.
04

Conceptos Eléctricos Clave

Para trabajar con Arduino sin quemar componentes, necesitas entender tres conceptos fundamentales de la electrónica: voltaje, corriente y resistencia.

⚡
Voltaje (V)
La "presión" que empuja la electricidad. Arduino trabaja a 5V. Símbolo: V. Medidor: Voltímetro.
〜
Corriente (I)
El flujo de electrones. Se mide en Amperios (A). Los pines Arduino dan máx. 40mA por pin.
Ω
Resistencia (R)
Oposición al flujo de corriente. Se mide en Ohms (Ω). Protege componentes.

La relación entre estos tres se expresa en la Ley de Ohm: V = I × R

// CÁLCULO PRÁCTICO
Para conectar un LED (2V, 20mA) a 5V de Arduino:
R = (5V – 2V) / 0.020A = 150Ω → usa una resistencia de 220Ω (valor estándar más cercano).
05

El Protoboard

El protoboard (o breadboard) es una placa con orificios interconectados que permite armar circuitos sin soldar. Es la herramienta más usada para prototipos rápidos con Arduino.

Filas centrales (a–e y f–j)

Los orificios de cada fila están conectados horizontalmente en grupos de 5. Inserta componentes aquí para conectarlos entre sí.

Carriles de alimentación (+ y −)

Las columnas laterales marcadas con rojo (+) y negro (−) van conectadas a 5V y GND de Arduino respectivamente. Son el suministro de toda la placa.

Cables Dupont

Son los cables con punta dorada para conectar el protoboard con Arduino. Vienen en versiones Macho–Macho, Macho–Hembra y Hembra–Hembra.

Regla de oro: no cruzar cables

Mantén el cableado ordenado y corto para evitar errores de conexión y cortocircuitos accidentales.

06

El IDE de Arduino

El Arduino IDE (Integrated Development Environment) es el programa donde escribes y subes el código a tu placa. Es gratuito y compatible con Windows, Mac y Linux.

Instalar el IDE

Descarga desde arduino.cc/en/software. Recomendado: Arduino IDE 2.x.

Seleccionar la placa

En Herramientas → Placa → selecciona "Arduino Uno" o el modelo que tengas.

Seleccionar el puerto

Herramientas → Puerto → elige el COM correspondiente (en Windows) o /dev/ttyUSB (en Linux/Mac).

Estructura básica de un programa

Todo sketch Arduino tiene dos funciones obligatorias: setup() que corre una vez al inicio y loop() que se repite continuamente.

Estructura mínima de un Sketch
// Variables globales (si las necesitas)
int ledPin = 13;

// setup() se ejecuta UNA VEZ al encender
void setup() {
  pinMode(ledPin, OUTPUT); // configurar pin como salida
}

// loop() se repite INFINITAMENTE
void loop() {
  digitalWrite(ledPin, HIGH); // encender LED
  delay(1000);               // esperar 1 segundo
  digitalWrite(ledPin, LOW);  // apagar LED
  delay(1000);               // esperar 1 segundo
}

Proyecto Final: LED Parpadeante

🎯 Objetivo del Minicurso

Construir un circuito con un LED externo que parpadea de manera controlada usando Arduino Uno. Este proyecto integra todos los conceptos aprendidos: conocimiento de la placa, uso del protoboard, cálculo de resistencias y programación básica.

Materiales necesarios

× 1 Placa Arduino Uno + cable USB
× 1 Protoboard (breadboard)
× 1 LED de cualquier color (5mm)
× 1 Resistencia de 220Ω (rojo-rojo-marrón)
× 2 Cables Dupont Macho-Macho
× 1 Computadora con Arduino IDE instalado
08

Código del Proyecto

El código siguiente hace que el LED externo conectado al pin 9 parpadee con intervalos personalizables. Cópialo en el IDE, selecciona la placa y el puerto, y presiona el botón de subir (→).

LED_Parpadeante.ino
/*
  PROYECTO: LED Parpadeante
  Descripción: Enciende y apaga un LED externo
               conectado al pin digital 9.
  Autor: Guía Arduino desde Cero
  Fecha: 2024
*/

// ──── CONFIGURACIÓN ────
const int LED_PIN = 9;   // pin digital donde está el LED
int tiempoEncendido  = 500; // ms que el LED permanece encendido
int tiempoApagado   = 500; // ms que el LED permanece apagado

// ──── SETUP ────
void setup() {
  pinMode(LED_PIN, OUTPUT); // configurar como salida
  Serial.begin(9600);        // iniciar comunicación serial
  Serial.println("LED Parpadeante iniciado");
}

// ──── LOOP ────
void loop() {
  digitalWrite(LED_PIN, HIGH);        // encender
  Serial.println("LED: ON");
  delay(tiempoEncendido);

  digitalWrite(LED_PIN, LOW);         // apagar
  Serial.println("LED: OFF");
  delay(tiempoApagado);
}
// EXPERIMENTA
Modifica los valores de tiempoEncendido y tiempoApagado para cambiar la velocidad del parpadeo. Prueba valores como 100, 250 o 2000 ms.
09

Diagrama del Circuito

Conecta los componentes tal como se muestra en el diagrama. Recuerda que el LED tiene polaridad: la pata más larga (ánodo) va al lado positivo del circuito.

Diagrama esquemático · LED Parpadeante con Arduino Uno

Conexión paso a paso

Cable desde pin D9 de Arduino → fila del protoboard (ej. fila 10, columna a).

Insertar la resistencia

Resistencia de 220Ω en la misma fila que el cable del pin 9. El otro extremo en otra fila vacía.

Insertar el LED

Pata larga (ánodo +) en la fila donde termina la resistencia. Pata corta (cátodo −) en otra fila.

Cable a GND

Cable desde la fila del cátodo (−) del LED hasta el pin GND de Arduino. ¡El circuito está completo!

// VERIFICA ANTES DE ENCENDER
Revisa dos veces que el LED esté orientado correctamente (pata larga al +) y que la resistencia esté siempre presente. Un LED sin resistencia se quema en segundos.
